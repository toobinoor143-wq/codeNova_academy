# README.md — CodeNova Academy

## 1. Which HTML elements did you use to structure the website?

I used semantic HTML elements such as <header>, <nav>, <main>, <section>, <article>, and <footer> to structure my website. I also used <h1>, <h2>, <h3>, <p>, <a>, <span>, <ul>, and <li> to display headings, paragraphs, navigation links, course information, and lists.

## 2. How did you arrange the course cards?

I used CSS Grid with `grid-template-columns: repeat(3, minmax(0, 1fr))` to arrange the six course cards in three columns on desktop screens. I used `gap` to maintain consistent spacing between the cards. On tablet screens, the cards change to two columns, and on mobile screens, they stack into a single column.

## 3. Which CSS property did you find most useful, and why?

I found the `display: grid` property most useful because it helped me arrange the six course cards neatly in rows and columns. It also made it easier to create a consistent layout for different screen sizes.

## 4. What problem did you face during development, and how did you solve it?

One problem I faced was making the website look good on different screen sizes. The course cards and other sections needed proper spacing and alignment. I solved this problem by using CSS media queries, adjusting the grid columns, and changing padding and font sizes for smaller screens.

## 5. How did you make your website responsive?

I made my website responsive by using a flexible container width, CSS Grid, Flexbox, and CSS media queries. I used a breakpoint at 768px for tablet screens and 480px for mobile screens. These adjustments help the navigation, course cards, About section, Learning Journey, and footer adapt to different screen sizes.
